## Objective
The objective of this assignment is to perform a one-sample t-test using Python to determine whether the sample mean differs significantly from a hypothesized population mean.

## Data Used
Sample Data: [5.2, 5.4, 5.1, 5.6, 5.3, 5.8]  
Hypothesized Mean: 5.5  

## Tasks Performed
- Calculated sample mean  
- Performed one-sample t-test  
- Computed t-statistic and p-value  
- Determined confidence interval  
- Interpreted results at 0.05 significance level  
- Visualized results using graphs  

## Tools & Libraries
- Python  
- NumPy  
- SciPy  
- Matplotlib  
- Google Colab  

## Result
- t-Statistic: -0.939  
- p-Value: 0.3907  

## Conclusion
At the 0.05 significance level, the null hypothesis is not rejected.  
There is no sufficient evidence to conclude that the population mean differs from 5.5.
