# Smart Restaurant Service Efficiency and Customer Experience Simulation

## Simulation and Modeling Lab Project

This project simulates a custom restaurant system and compares it with a KFC-inspired benchmark restaurant using statistical analysis, customer satisfaction analysis, customer mood analysis, and two-sample t-test evaluation.

---

# Project Objective

The main objective of this project is to analyze restaurant operational performance using simulation and statistical modeling techniques.

The project evaluates:

- Customer waiting time
- Food quality
- Food affordability
- Customer satisfaction
- Customer mood
- Overall restaurant performance

The system dynamically generates restaurant scenarios using random simulation techniques and compares the results with a benchmark fast-food restaurant system.

---

# Features

- Restaurant customer simulation

- Waiting time analysis

# Conclusion

This project demonstrates how simulation and statistical analysis can be used to compare restaurant operational performance, customer satisfaction, affordability, and customer experience against a benchmark restaurant system.

The project dynamically creates different customer scenarios and determines whether the custom restaurant can outperform the benchmark restaurant based on operational efficiency and customer experience.
